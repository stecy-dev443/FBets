# FBets

A polished, mobile-first sports betting experience prototype.

## Project status

FBets is a demonstration frontend. Fixtures, markets and odds are illustrative demo data; no live sports feed, real-money wagering, deposits or withdrawals are connected.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js App Router
- React
- TypeScript
- CSS

## Safety and compliance

This prototype uses virtual stakes only. Before any real-money functionality is considered, the product requires appropriate licensing, age and location controls, responsible-play safeguards, payment compliance and legal review for each operating jurisdiction.
